# Offertio Pilot Execution Plan

## Objective
Turn Offertio from a polished product into a business with the first paying pilot customers.

## 14-Day Mission
- 50 handpicked target businesses
- 15 replies
- 8 demo calls
- 3 pilot customers
- 2 paying customers

## Best first ICP
### Primary
- cleaning companies
- small handwork/service businesses
- owner-led teams with 1-10 people

### Strong indicators
- creates offers after site visits
- still uses Word, PDF templates, Excel, email, or WhatsApp
- complains about admin happening later at night
- does not want a full CRM/ERP rollout

## Offer
### Founder Pilot
- direct setup help
- founder access / fast support
- discounted early pricing
- close feedback loop

Suggested structure:
- 14-day guided trial
- then founder pilot price
- CHF/EUR 19-29 per month for first pilot users

## Outreach cadence
### Day 1-2
- build first target list of 50 businesses
- split into 2 verticals only
- prepare demo link + screenshots + short intro text

### Day 3-5
- send first 20 cold emails
- 10 WhatsApp/DM follow-ups where appropriate
- call 10 businesses directly

### Day 6-7
- run demos
- log objections
- refine outreach copy

### Day 8-10
- send second wave to another 20-30 leads
- reuse strongest message angle
- ask first interested users for pilot commitment

### Day 11-14
- onboard first pilots
- watch first real document creation
- capture objections, friction, pricing feedback
- convert active pilot users to paying users

## Lead sourcing checklist
For each business collect:
- company name
- city / region
- trade / segment
- owner/contact name if possible
- email
- phone
- current workflow clues
- why Offertio is relevant

## Demo checklist
1. What do you use today for offers/invoices?
2. What is annoying about it?
3. Show Offertio from login to sent document in <10 minutes
4. Ask: would this save you time in your real workflow?
5. Ask: would you test this with one real customer case this week?

## Objections to track
- already using something
- too small for software
- doesn’t want another tool
- wants accounting integration
- wants desktop workflow
- pricing concerns

## What success looks like
- people use Offertio for real documents
- at least two businesses pay
- you know which segment responds best
- you have real language from customers for future landing/copy
