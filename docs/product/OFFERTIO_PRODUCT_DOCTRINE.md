# Offertio Product Doctrine

## What Offertio is
Offertio is the fastest and most professional way for small DACH businesses to create offers and invoices directly after a customer appointment.

It is:
- mobile-first
- calm
- professional
- DACH-aware
- simpler and cheaper than old CRM/ERP dinosaurs

## What Offertio is not
Offertio is not:
- a heavy CRM
- an all-in-one ERP
- a backoffice monster
- a feature farm
- software for software people

## Core promise
After the customer appointment, the user should be able to:
1. capture what matters
2. generate a professional document
3. send it immediately
4. look serious in front of the customer
5. avoid another office evening

## Product principles
### 1. Simplicity is part of the value
If Offertio feels complicated, it breaks its own promise.

### 2. The workspace matters more than the marketing
A strong landing with a weak app is failure.

### 3. DACH complexity stays behind the curtain
Country logic should exist, but it should not feel bureaucratic.

### 4. Professional output beats feature quantity
The user pays for fast, trustworthy documents — not for dashboards full of modules.

### 5. Mobile is the real environment
Responsive is not enough. The product should feel natural on the phone.

## Ideal user reaction
“This feels built for businesses like mine. I can use this today.”

## Design north star
A quiet instrument.
Not flashy. Not generic SaaS. Not startup hype.
A premium operational tool for real field work.

## Product filter question
For every feature or screen change, ask:
Does this help the user create and send a professional document faster and with less friction after the appointment?

If not, it is lower priority.
