# Offertio Hero Trailer Recording Brief

## Goal
Make the landing feel like a premium product trailer that starts instantly in the hero.

This is **not** a tutorial. It is a **conversion asset**.
The viewer should understand this in seconds:

1. A real customer request comes in
2. Offertio turns it into a clean offer fast
3. Swiss QR invoice is already there
4. The result looks trustworthy enough to send immediately

## Format
- Length: **20–35 seconds**
- Best target: **~28 seconds**
- Ratio: **16:9** for website hero
- Capture style: **mobile-first UI**, tight crops, finger motion, no talking required
- Playback assumption: **autoplay muted first**
- Edit style: premium, fast, clean, no gimmicky zoom spam

## Core principle
**Motion first. Explanation second.**

The first 3 seconds need to prove momentum.
Do not waste time with logos, intros, or setup.
Start with the work happening.

## Trailer script / beat order

### Beat 1 — Hook (0:00–0:03)
**Visual:** Land directly on a customer request / messy input moment.
- WhatsApp or request text visible briefly
- Immediate cut into Offertio input screen

**On-screen text option:**
- `Anfrage rein.`
- `Offerte raus.`

**Why:** instantly frames the job-to-be-done.

---

### Beat 2 — Build the quote fast (0:03–0:10)
**Visual:**
- Add customer name
- Add 1–2 positions
- Add amount / material / service line
- Quick confident finger taps

**What matters:**
- Show speed
- Show clarity
- Show this is done on a phone without friction

**On-screen text option:**
- `Positionen in Sekunden erfassen`

---

### Beat 3 — Totals lock in (0:10–0:15)
**Visual:**
- Total updates
- MWST / pricing resolves cleanly
- UI feels reliable and polished

**On-screen text option:**
- `Sauber berechnet`

**Why:** gives the “this is trustworthy” moment.

---

### Beat 4 — PDF reveal (0:15–0:22)
**Visual:**
- Transition into generated PDF
- Show professional document layout
- Hold long enough to register quality

**On-screen text option:**
- `Professionelles PDF automatisch erstellt`

**Important:**
This is the prestige shot. Let it breathe for a moment.

---

### Beat 5 — QR invoice hero shot (0:22–0:26)
**Visual:**
- Tight crop on Swiss QR-Rechnung block
- Amount visible
- Feels like “ready to send, ready to get paid”

**On-screen text option:**
- `Swiss QR-Rechnung inklusive`

**Why:** this is one of the strongest Swiss-specific trust triggers.

---

### Beat 6 — Send / finish (0:26–0:30)
**Visual:**
- Tap send / export / share
- End on the polished final state
- Optional subtle success state

**On-screen text option:**
- `Bereit zum Senden`

---

## Recommended shot list
1. **Cold open:** incoming request / messy context
2. **Immediate app interaction:** user starts building the offer
3. **Add line items:** 2–3 quick but readable edits
4. **Pricing / total update:** numbers visibly settle
5. **PDF appears:** elegant reveal
6. **QR close-up:** trust + Swiss compliance moment
7. **Send action:** final payoff

## Capture instructions for Reshat
- Record the real product if possible, not a fake Figma walkthrough
- Use **steady finger movement**; avoid hesitant taps
- Keep UI clean before recording
- Use realistic sample data from a Swiss trade business
- Prefer **short takes per beat** over one long recording
- Make every shot usable without audio
- Avoid tiny text that disappears in hero crop
- Show enough movement in the first second so autoplay feels alive

## Editing notes
- Keep cuts tight
- Use subtle speed ramps only if they feel premium
- Avoid meme transitions or loud motion graphics
- Light ambient soundtrack is optional, but the trailer must still work muted
- If text overlays are used, keep them to **2–5 words max**
- Use contrasty framing so the hero still reads behind landing overlays

## Recommended overlay lines on the site
The landing implementation is already tuned for these messages:
- `Trailer läuft sofort`
- `Leere Anfrage rein.`
- `Saubere Offerte mit QR-Rechnung raus.`
- `~28s · silent-first · mobile shot`

## File handoff
When the final export is ready:
- save it as **`/public/demo.mp4`**
- optional poster already exists at **`/public/demo-poster.svg`**

The landing will autoplay the MP4 in the hero automatically.
If the file is missing, the site falls back to a premium placeholder state instead of breaking.

## Success criteria
The trailer is good enough if, within a few seconds, a cold visitor can feel:
- this is built for my kind of business
- this looks fast
- this looks trustworthy
- this gets me to a sendable PDF with QR invoice fast

## One-line direction
**Think Apple product trailer meets Swiss tradesman utility — short, calm, sharp, instantly credible.**
